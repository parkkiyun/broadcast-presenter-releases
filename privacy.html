스테이지큐 개인정보처리방침

시행일: 2026년 11월 25일 · 문의: kiyun0515@gmail.com

스테이지큐(Stagecue)는 교회·학교 방송실에서 찬양 가사, 성경, 사진·영상을 화면에 띄우는 프로그램입니다. 데스크톱 앱과 웹 버전(이 사이트)이 있습니다.

1. 따로 모으는 개인정보는 없습니다

스테이지큐에는 회원 가입이 없고, 개발자가 운영하는 서버로 사용자의 자료나 개인정보를 보내지 않습니다. 사용 통계·광고 추적도 하지 않습니다.

2. 자료가 저장되는 곳

  • 데스크톱 앱: 사용자 PC 안 (Windows 사용자 폴더의 앱 데이터)
  • 웹 버전: 사용자가 쓰는 브라우저 안 (IndexedDB·Cache 저장소). 브라우저 데이터를 지우면 함께 지워집니다.
  • 구글 드라이브 연결을 켠 경우: 사용자 본인의 구글 드라이브 "스테이지큐" 폴더

3. 구글 드라이브 연결

사용자가 직접 [구글로 연결]을 누른 경우에만 구글 계정으로 로그인합니다. 요청하는 권한은 drive.file 하나로, 스테이지큐가 만든 파일만 보고 고칠 수 있으며 드라이브의 다른 파일에는 접근할 수 없습니다.

  • 드라이브에 저장하는 것: 설정·템플릿, 찬양 라이브러리, 지금 순서와 저장한 순서, 성경 본문, 순서에 쓰인 그림·영상·음원
  • 계정 정보는 연결된 계정의 이메일 주소를 화면에 보여 주는 데에만 씁니다.
  • 로그인 토큰은 데스크톱 앱에서는 Windows 보안 저장소로 암호화해 PC 안에, 웹 버전에서는 브라우저 메모리에만 둡니다.
  • 구글에서 받은 정보를 제3자에게 주거나 팔지 않으며, 광고나 인공지능 학습에 쓰지 않습니다. 구글 API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 연결 끊기와 삭제

스테이지큐의 구름 단추 → [연결 끊기]를 누르면 로그인이 해제됩니다. 구글 계정의 서드 파티 앱 접근 권한에서도 언제든 해제할 수 있습니다. 드라이브의 "스테이지큐" 폴더와 PC·브라우저의 자료는 사용자가 직접 지울 수 있습니다.

5. 외부 서비스

사진 검색(Openverse), 유튜브 영상 넣기처럼 사용자가 직접 쓰는 기능은 해당 서비스에 검색어·영상 주소를 보냅니다. 각 서비스의 방침을 따릅니다.

6. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 시행일과 함께 알립니다.
